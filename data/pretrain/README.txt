Учебный корпус для pretrain небольшой языковой модели.

Назначение:
- проверка tokenizer -> dataset -> dataloader -> forward -> loss -> backward;
- проверка causal language modeling;
- smoke-test RoPE, RMSNorm, attention/FlashAttention, SwiGLU и MoE;
- проверка checkpointing и генерации после нескольких эпох.

Важно:
Этот корпус синтетический и намеренно небольшой. Он НЕ предназначен для обучения
полноценной языковой модели и НЕ является эталонным источником фактов.

Рекомендации:
1. Сначала обучите токенизатор на всех txt-файлах.
2. Для pretrain объединяйте документы с EOS между документами.
3. Перемешивайте документы/чанки, но не токены внутри чанка.
4. Не используйте одновременно topic-файлы и mixed_general_corpus.txt в одном
   эксперименте, иначе получите фактическое дублирование.
5. Для маленького учебного запуска разумно использовать context length 128-512.
6. Для проверки MoE отслеживайте долю токенов, попавших к каждому эксперту.
7. Смотрите train/validation loss и отдельно проверяйте overfit на маленьком подмножестве.
